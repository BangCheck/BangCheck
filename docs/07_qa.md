## 9. 사용 안내

1. 본 문서는 **CSV → 마크다운 미러**. 원본 갱신 시 수기 동기화.
2. 시나리오 시트 실행은 Google Sheet에서, `결과` 컬럼 Pass/Fail/Block/N/A 선택.
3. Fail 발견 시 → 이슈 본체로 등재 (`05-ux-web/` 또는 `06-ux-mobile/`).
4. 우선순위 [최상]부터 먼저 실행.
5. close 8 gates 충족 시 본 문서 카운터 갱신 + dashboard 동기화.
