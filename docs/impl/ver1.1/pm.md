## 화면별 점검

### 온보딩 / 로그인
- 소셜 로그인 버튼 노출·동작 정상
- 로그인 실패 시 에러 메시지 표현 (빈 화면 금지)
- 재진입 시 자동 로그인 여부

### 홈 / 방 목록
- 방이 없을 때 빈 상태 화면 (CTA 포함)
- 방 목록 로딩 스피너 표시
- 6개 상한 초과 시 안내 메시지

### 방 체크리스트
- 체크 항목 로딩 상태 표시
- 항목 없을 때 빈 상태 안내
- 커스텀 항목 최대 3개 제한 안내 (초과 시 비활성 + 메시지)
- 저장 성공 / 실패 피드백

### 비교 리포트
- 리포트 생성 중 로딩 표시
- 비교 대상 없을 때 빈 상태 + 방 추가 유도
- 에러 발생 시 재시도 유도 메시지

### 지도 탐색
- 지도 초기 로딩 스피너
- 마커 없을 때 빈 상태 안내
- 검색 결과 없음 안내

### 주소 자동완성
- 입력 중 로딩 표시 (debounce 중 스피너)
- 결과 없음 안내
- API 오류 시 폴백 메시지 (재시도 or 직접 입력 유도)
